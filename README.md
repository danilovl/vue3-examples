# Examples for Vue3 + Pinia + TypeScript

Project with examples of using various features of **Vue 3**, **Pinia**, **TypeScript**, and **Vite**.

![Homepage](/readme/homepage.png?raw=true "Homepage")

## 📝 Description

This repository is a collection of practical examples and best practices for Vue 3 developers. It covers everything from basic reactivity and component communication to advanced patterns like dynamic forms, custom directives, and the latest features introduced in Vue 3.5+.

### Key Features
*   **Composition API**: Extensive use of `<script setup>` and composables.
*   **State Management**: Examples of using Pinia for global state.
*   **Forms & Validation**: Integration with VeeValidate 4.
*   **Advanced Patterns**: Dynamic layouts, async components, and custom hooks.
*   **Vue 3.5+**: Latest features like `useTemplateRef` and extended `defineModel`.

## 🚀 Examples

The following examples are implemented in this project:

*   **Todo (CRUD)**: Basic list management with Pinia.
*   **Dynamic layout**: Switching layouts based on route meta.
*   **Counter**: Simple state and mixins comparison.
*   **Form input bindings**: Various input types and two-way binding.
*   **Lifecycle hooks**: Visualization of component lifecycle.
*   **Axios**: Fetching data from an external API.
*   **Teleport**: Moving components to different DOM nodes.
*   **Suspense**: Handling async component loading states.
*   **Provide and inject**: Deep component tree communication.
*   **Multiple v-models**: Binding multiple values to a single component.
*   **Vee validate form**: Complex form validation logic.
*   **Filters**: Custom text formatting (mimicking Vue 2 filters).
*   **Key code**: Handling keyboard events.
*   **Emit**: Child-to-parent communication (includes computed and v-model emits).
*   **Directives**: Basic and custom directive implementation.
*   **Ref attribute**: Accessing DOM elements.
*   **Slot**: Named and scoped slots.
*   **Plugin translate**: Simple i18n plugin example.
*   **Watchers**: Reacting to data changes.
*   **Advanced**:
    *   **Dynamic Form**: A schema-driven form builder and renderer using VeeValidate.
    *   **Async Suspense**: Advanced async data fetching patterns.
    *   **Vue 3.5 Features**: `useTemplateRef`, `defineModel`, and custom hooks.
